# Clarid Skin — Landing Page

Página promocional (afiliado) do **Clarid Skin Clareador Dérmico Corporal**, com links de compra para o anúncio no Mercado Livre.

## Tecnologias

- HTML + CSS + JavaScript puro, em um único arquivo (`index.html`)
- Meta Pixel (PageView + InitiateCheckout no clique dos botões)
- Google Ads tag (conversão no clique dos botões)
- Hospedagem estática na Netlify (`netlify.toml` publica a raiz do repositório)

## Rodar localmente

Abra `index.html` no navegador, ou rode:

```bash
netlify dev --port 8889
```
